# DRF LMS Project 

Веб-приложение для управления обучением (LMS) с использованием Django REST Framework.

## Новые фичи в ДЗ 30.2
- **Подсчёт и вывод данных:** В эндпоинтах курсов выводится количество уроков (`lessons_count`) и их подробный список.
- **Модель платежей:** Добавлена сущность `Payment` с возможностью фиксировать оплаты курсов/уроков наличными или переводом.
- **Инструмент фикстур:** Подготовлены демонстрационные данные по платежам для быстрого наполнения БД.
- **Фильтрация и сортировка:** Подключен пакет `django-filter` для тонкого поиска платежей по курсу, уроку, способу оплаты и сортировке по дате.
- **История в профиле:** В эндпоинт профиля пользователя встроена полная вложенная история его персональных платежей.


## Стек технологий
- Python 3.12+
- Django 5.x
- Django REST Framework (DRF)
- Django Filter (фильтрация API)
- Pillow (для работы с изображениями)
- Flake8 (линтер кода)
- Python-dotenv (управление секретами)

## Как запустить проект локально

1. **Клонируйте репозиторий и перейдите в ветку домашней работы:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd drf_lms_project
   git checkout feature/homework_30.1
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   ```
**Настройте переменные окружения:**
   - Скопируйте шаблон файла конфигурации:
     ```bash
     cp env.example .env
     ```
     *(Если вы на Windows в PowerShell, используйте команду: `cp env.example .env` или вручную переименуйте скопированный файл в `.env`)*
   - Откройте созданный файл `.env` и укажите в переменной `SECRET_KEY` ваш секретный ключ Django.

**Установите все зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

**Примените миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

**Загрузите демонстрационные данные из фикстуры:**
   ```bash
   python manage.py loaddata users/fixtures/payments_data.json
   ``` 

**Создайте суперпользователя (администратора):**
   ```bash
   python manage.py createsuperuser
   ```
   *Система попросит ввести Email и пароль (авторизация по умолчанию настроена через Email).*

**Запустите сервер разработки:**
   ```bash
   python manage.py runserver
   ```
   Проект будет доступен по адресу: `http://127.0.0`

# Примеры использования API (Эндпоинты)

- `http://127.0.0` — Главная страница-навигатор по проекту.
- `http://127.0.0materials/courses/` — Список курсов со встроенными уроками и их счётчиком.
- `http://127.0.0users/payments/` — Список всех платежей.
  - *Сортировка по дате (от новых к старым):* `?ordering=-payment_date`
  - *Фильтр по способу оплаты:* `?payment_method=cash`
  - *Фильтр по курсу:* `?paid_course=1`
- `http://127.0.0users/profile/1/` — Профиль пользователя, содержащий вложенную историю его платежей (`payments_history`).
